## Fruit calorie Counter 
A simple  Python utility that allows users to look up the caloric content of various fruits based on standard serving sizes.
## Description
This script uses a dictionary to store fruit names and their calorie counts. When a user inputs a fruit name, the program performs a lookup and displays the calories. If the item isn't in the database, the program exits silently.

#### Running Tests
To run test on calories.py,and to ensure that the application functions as intended execute the following command:
```bash
cd calories
Run python calories.py

Input: Type the name of a fruit when prompted (e.g., Apple or apple).

Output: The script will display the calorie count if the fruit is found.

Example
Item: apple
Calories: 130
